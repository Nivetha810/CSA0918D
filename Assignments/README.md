# Java Assignments

This directory contains the five Java assignment solutions, organized by course outcome.

- Assignment 1: CO1 – Java fundamentals and OOP
- Assignment 2: CO2 – Strings and Collections
- Assignment 3: CO3 – Exceptions and Multithreading
- Assignment 4: CO4 – Event-driven GUI design
- Assignment 5: CO5 – Files, persistence and JDBC

Each assignment folder contains runnable Java source, an answer/design note, and a README with compile/run guidance. Experimental timings, screenshots and database-specific execution evidence must be generated in the student's own environment.
